# Remo_ox_downloader_web_app (v0.1) 🌐⚡

تطبيق ويب حديث ومتجاوب بالكامل لتحميل الفيديوهات والمقاطع الصوتية بجودة عالية من مختلف المنصات العالمية (يوتيوب، فيسبوك، إنستغرام، تيك توك، إكس/تويتر)، مبني باستخدام **Python** و **Streamlit** و **yt-dlp** ومصمم ليعمل بسلاسة على كافة الأجهزة: **الهواتف الذكية (iPhone عبر Safari، و Android عبر Chrome)** وكذلك أجهزة الكمبيوتر (**Mac, Windows, Linux**).

---

## 🌟 مميزات الإصدار (v0.1)

1. **متوافق مع جميع الأجهزة (Cross-Platform):**
   * يعمل مباشرة عبر متصفح الويب دون الحاجة لتثبيت أي برامج أو ملفات `.exe`.
   * متجاوب بالكامل مع شاشات الهواتف المحمولة والتابلت والكمبيوتر.
2. **تحميل مباشر للجهاز (Direct Device Download):**
   * بمجرد انتهاء المعالجة، يظهر زر تحميل رسمي يقوم بحفظ الملف فوراً في مجلد **Downloads** أو تطبيق **Files** على الآيفون والأندرويد.
3. **دعم كامل للغتين (العربية والإنجليزية):**
   * واجهة تدعم اتجاه الكتابة من اليمين لليسار (RTL) بالعربية مع زر تبديل فوري.
4. **تحديد الصيغة والجودة:**
   * فيديو عالي الدقة (MP4) حتى 1080p أو استخراج صوت نقي (MP3 192kbps).
5. **معمارية برمجية كائنية التوجه (Clean OOP Architecture):**
   * كود نظيف مقسم لوحدات مستقلة وسهل الصيانة والتطوير.
6. **تنظيف تلقائي للذاكرة (Auto Temp Cleanup):**
   * حذف تلقائي للملفات المؤقتة من السيرفر لحفظ المساحة والأمان.

## 🏗️ معمارية المشروع (OOP Architecture)

تم بناء المشروع بالكامل وفق أسلوب **Object-Oriented Programming (OOP)**:

```text
Remo_ox_downloader_web_app/
│
├── app.py                      # كلاس التحكم الرئيسي بالواجهة (RemoOxWebApp)
├── requirements.txt            # مكتبات بايثون المطلوبة (streamlit, yt-dlp, requests)
├── packages.txt                # أمر تثبيت محرك FFmpeg تلقائياً على سيرفرات لينكس
├── README.md                   # التوثيق الشامل ودليل النشر
│
├── .streamlit/
│   └── config.toml             # تخصيص ثيم الوضع الليلي (Dark Theme) والأداء
│
└── core/
    ├── __init__.py
    ├── config.py               # كلاس إدارة الإعدادات والمسارات (AppConfig)
    ├── downloader.py           # كلاس محرك التحميل والدمج (MediaDownloader)
    ├── translations.py         # كلاس إدارة اللغات والترجمة (TranslationManager)
    └── cleaner.py              # كلاس تنظيف الملفات المؤقتة من السيرفر (TempCleaner)
```

### تفصيل الكلاسات (Classes Breakdown):
* **`RemoOxWebApp` (`app.py`):** الكلاس المركزي المسؤول عن دورة حياة التطبيق، إدارة الجلسات (`st.session_state`)، رسم الواجهة، والتعامل مع نقرات المستخدم.
* **`MediaDownloader` (`core/downloader.py`):** المسؤول عن الاتصال بمحرك `yt-dlp` واستخراج الميتاداتا، وتطبيق إعدادات تخطي حظر المنصات، ودمج الصوت والصورة عبر `FFmpeg`.
* **`TranslationManager` (`core/translations.py`):** المسؤول عن توفير نصوص اللغتين العربية والإنجليزية وتغيير اتجاه الصفحة ديناميكياً (RTL/LTR).
* **`AppConfig` (`core/config.py`):** يحتوي على الثوابت، رقم الإصدار (v0.1)، وفحص وجود محرك `FFmpeg`.
* **`TempCleaner` (`core/cleaner.py`):** يقوم بفحص مجلد التنزيلات المؤقتة وحذف الملفات القديمة لتفادي امتلاء قرص السيرفر.

## 🚀 خطوات نشر التطبيق على Streamlit Cloud والحصول على رابط HTTPS مجاني

### الخطوة 1: رفع مجلد المشروع إلى GitHub
يمكنك رفع مجلد `Remo_ox_downloader_web_app` إما:
* **كمستودع جديد مستقل (موصى به ليكون خفيفاً وسريعاً):**
  1. أنشئ مستودعاً جديداً على GitHub باسم: `Remo_ox_downloader_web_app`.
  2. ارفع ملفات هذا المجلد بداخله (`app.py`, `requirements.txt`, `packages.txt`, ومجلد `core`).
* **أو إبقاؤه داخل مستودعك الحالي:**
  - رفع المجلد الجديد داخل مستودعك الأساسي.

### الخطوة 2: الدخول إلى منصة Streamlit
1. اذهب إلى: [share.streamlit.io](https://share.streamlit.io/) وسجل الدخول بحساب GitHub الخاص بك.
2. اضغط على الزر الأزرق: **"Create app"** (أو **New app**).
3. املأ البيانات كالتالي:
   * **Repository:** اختر مستودعك (مثال: `remonedward/Remo_ox_downloader_web_app`).
   * **Branch:** `main` (أو `master`).
   * **Main file path:** اكتب `app.py` (أو `Remo_ox_downloader_web_app/app.py` إذا كان داخل مجلد فرعي).
   * **App URL:** اختر رابطاً مخصصاً يعجبك، مثلاً:  
     `remo-ox-downloader.streamlit.app`
4. اضغط على **"Deploy!"**.

### الخطوة 3: التثبيت التلقائي والموقع الحي!
* سيقوم سيرفر Streamlit بقراءة ملف `packages.txt` وتثبيت محرك `ffmpeg` تلقائياً.
* سيقوم بقراءة `requirements.txt` وتثبيت المكتبات.
* في غضون دقيقة واحدة، سيصبح تطبيقك متاحاً برابط HTTPS رسمي تشاركه مع أي شخص لديه آيفون أو أندرويد أو كمبيوتر!
